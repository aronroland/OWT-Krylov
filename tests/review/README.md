# Numerical review regressions

These cases specify desired behavior and are not marked WILL_FAIL. The original
20 probes passed after updating to upstream `4bd549b` and applying the fixes;
see [completion status](../../docs/REMAINING_REGRESSIONS_STATUS.md) for final evidence.
Foundation and expanded contract checks are ordinary CTest tests; the original
review probes and LAPACK harmonic contracts are opt-in.
All inputs are generated by the repository C++ sources. Run from the repository
root; build products and CTest logs remain in the repository.

```bash
mkdir -p build-review
export TMPDIR="$PWD/build-review"
cmake -S . -B build-review -DCMAKE_CXX_COMPILER=/usr/bin/g++ \
  -DOWT_KRYLOV_BUILD_REVIEW_TESTS=ON
cmake --build build-review
ctest --test-dir build-review --output-on-failure
```

The MPI cases additionally require OWT_KRYLOV_ENABLE_MPI=ON with a matching
compiler and launcher. Each test has a timeout. The timer case intentionally
disables optional copy elision to exercise legal C++ return behavior.

`bash tests/review/run_review.sh` runs the README's standard build/CTest
workflow first and then the review suite. It preserves commands, exit codes,
environment metadata and logs under `docs/review-2026-09-12/evidence/`.
An existing build cache is reused and its feature options are recorded; the
default README command does not reset cached options. This is fresh synthetic
solver testing, not archived-reference validation, figure regeneration, or a
fresh SpecWave/Limon reproduction.

Use `bash tests/review/run_review.sh serial` for the baseline and serial cases,
or `bash tests/review/run_review.sh advanced` for the optional-feature build in
`build-review-mpi`. The advanced mode explicitly uses `/usr/bin/mpicxx.openmpi`
and `/usr/bin/mpiexec.openmpi`, with MPI, PETSc, LAPACK and OpenMP Target enabled.
It runs the original suite plus the MPI and harmonic-extraction regressions;
the serial regressions need not be repeated. Adapt the two tool paths for a
different installation. OpenMP host fallback is not device validation.

The `cases` mode reruns the review builds after modifying regression cases,
without repeating the original cached default-build attempt. Advanced runs
also execute synthetic benchmark smoke tests at `64 32` (serial driver) and
`16 4` (two-rank distributed driver). Their times are not performance claims.
The `metadata` mode records tool versions, source hashes and the worktree state
without running tests. Logs retain the latest invocation for each command label.

## Foundation patch workflow

The ordinary (not opt-in) foundation tests cover safe norms, nonfinite solver
inputs, borrowed solution/candidate lifetimes, repeated split-SSOR pipelined
solves at block sizes 5 and 1296, and timing with copy elision disabled. MPI
tests include unequal owned sizes and nonfinite data on just one rank.

Run the documented serial and matching-MPI builds with separate preserved
evidence for each patch stage:

```bash
OWT_REVIEW_RUN_ID=foundation-before bash tests/review/run_review.sh foundation
OWT_REVIEW_RUN_ID=foundation-after bash tests/review/run_review.sh foundation
```

Use a new run ID for each invocation. Named runs refuse to overwrite an existing
evidence directory and write under `docs/review-2026-09-12/runs/`. This preserves
the original review evidence. The `foundation` mode runs all ordinary tests,
including the new tests, but does not run the optional review
probes. Use `cases` with a separate run ID for the full review
inventory. These tests run synthetic operators, not an application simulation;
the MPI pipelined fixture has rank-local matrices and does not validate halos.

For serial AddressSanitizer/UndefinedBehaviorSanitizer testing with Clang:

```bash
OWT_REVIEW_RUN_ID=foundation-sanitizers bash tests/review/run_review.sh sanitizers
```

This builds ordinary tests and serial review probes in `build-review-sanitizers`, with leak detection
and fail-fast sanitizer settings. It does not claim MPI sanitizer coverage.
The sanitizer runner sets its own stack limit to 8192 KiB and records the
inherited and effective limits; unlimited stacks can conflict with ASan's
shadow-memory layout. The parent shell and system settings are not changed.
The MPI norm tests also exercise `MPI_COMM_SELF`; pipelined tests check that
exceptional norm fallback reductions are included in telemetry.

## Completion workflow

```bash
OWT_REVIEW_RUN_ID=completion-cases bash tests/review/run_review.sh cases
OWT_REVIEW_RUN_ID=completion-sanitizers bash tests/review/run_review.sh sanitizers
```

Choose unused run IDs. Expanded ordinary tests cover native/split SSOR at
omega 0.5, 1 and 1.5, float/double scaled solves, final-iteration acceptance,
ILU numeric updates, and changing-operator recycling. MPI contracts cover
unequal ownership, collective invalid-input rejection, wide blocking and
nonblocking reduction batches, unchanged-pattern overlap updates and
one-rank pattern rejection. A directed halo case checks exported interior
send-buffer lifetime at block size 1296. LAPACK contracts cover nonorthogonal
flexible trial bases, full conjugate pairs, fixed capacity and infinite
generalized eigenvalues. These are fresh synthetic library regressions, not
TRITON-C/ADH integration qualification or performance evidence.
